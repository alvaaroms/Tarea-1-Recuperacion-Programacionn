# Recuperación Programación - Notas del Curso

## Descripción
Aplicación de consola en Java para gestionar 10 notas de un curso.  
El programa permite introducir notas con decimales y realizar distintas operaciones mediante un menú repetitivo.

## Objetivo
Repasar programación estructurada utilizando:
- arrays
- condicionales
- bucles
- métodos estáticos
- menú con `while`

## Funcionalidades
- Registrar 10 notas
- Mostrar todas las notas
- Calcular la media
- Mostrar la nota más alta
- Mostrar la nota más baja
- Contar aprobados
- Contar suspensos
- Buscar una nota por posición
- Ordenar las notas de mayor a menor

## Requisitos cumplidos
- Uso de un array para almacenar las notas
- Métodos estáticos separados
- Menú repetitivo con `while`
- Uso de condicionales y bucles
- Código limpio y organizado
- Entrada de notas con decimales

## Estructura del proyecto
- `src/Main.java` → clase de inicio del programa
- `src/RequisitosObligatorios/NotasDelCurso.java` → lógica principal de la aplicación

## Cómo ejecutar
1. Abrir el proyecto en IntelliJ IDEA
2. Ejecutar la clase `Main`
3. Usar el menú para introducir y consultar las notas

## Notas
- Las notas se introducen entre `0.00` y `10.00`
- La posición de búsqueda va de `1` a `10`
- La lista se ordena de mayor a menor sin crear otro array
